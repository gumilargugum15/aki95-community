# Project Rules

- Laravel 12 backend
- React + TypeScript frontend
- Gunakan Repository Pattern
- Gunakan Service Layer
- Ikuti PSR-12 untuk PHP
- Gunakan ESLint dan Prettier untuk frontend
- Jangan mengubah file yang tidak berkaitan
- Jangan membuat kode duplikat
- Selalu gunakan reusable component
- Selalu buat commit yang rapi
- Jangan menyimpan file .env ke repository
